READ ME 

Time-normalized data is shown for specific variables and dimensions (given in filename) for all participants individually.
The participant number is shown on the left side of each graph.
The group average (average of the average over all participants) is shown in the background in gray shaded area. 
Left side data (individual strides) is shown in blue and Right side data is shown in Red. 
Units on the y-axis are according to descriptor file of the .MAT dataset. 
Note that axis limits are not standardized across sub-plots. 
X-axis is the percentage of stride, with data being normalized to 1001 points.
